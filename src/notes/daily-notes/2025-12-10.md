# Implement statistics about pickers
On logging in, the log in datetime is sent to server, is saved, session-id is generated and sent back.
Session-id is used to identify the session in subsequent requests.
> We wish to track these actions:
- Log ins
- Log outs
- Order packing time
- Order picking time
- Total time spent working (== sum of all order times)
Picker logs in. -> Session created -> SessionId saved on frontend -> subsequent requests use sessionId (logout, picking, packing)
